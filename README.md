# 拾光机位 · Seek the Light

> 在人多的地方，找到没人的角度。

一个把**本机风景照**、**小众机位**和**地理坐标**放在一起的摄影社区原型：照片来自你桌面「素材」文件夹里的真实影像，落回它们被拍下的城市；每个用户都能上传作品，标注时间、季节、时段、站位和镜头朝向；所有人的作品公开展示，可以点赞、评论。

- 前端：原生 HTML / CSS / JavaScript + 原生 WebGL，零构建、零第三方依赖，移动端优先
- 后端：Python 标准库 `http.server` + SQLite + Pillow，无 Web 框架
- 当前数据：**8 个实拍机位 / 29 张实拍作品 / 46 张本机风景照 / 5 座城市 / 11 种地貌档案 / 9 处世界地理**
- 机位库只展示有真实照片来源的机位；16 个程序生成的示例机位已从公开 API 隐藏，不再把生成图当实拍
- **3D 地球**：可拖拽旋转、滚轮/双指缩放、点击取经纬度，按「我的影像 / 机位 / 地貌」筛选
- 所有照片、坐标、作品与评论都保存在本机 `data/` 目录

## 功能

### 发现
- 首页主视觉直接使用本机风景照：镇江的五峰山大桥、扬州东关街的灯笼、张掖的丹霞
- 「本机影像」横向影像带：编号、标题、地点、拍摄日期
- 「在此刻」按当前季节与时段推荐机位
- 「地理」入口：3D 地球 + 可按位置/地貌切换的全屏背景
- 「在地机位」：从照片 GPS 里生长出来的江苏机位
- 季节推荐、最新作品、省份入口

### 机位库 · 只收实拍
- 只展示 8 个有真实照片来源的机位；16 个程序生成的示例机位已从公开接口隐藏
- **省 → 市 → 区县三级联动筛选**（江苏：南京/宿迁/扬州/镇江；甘肃：张掖）
- 每张卡片标明省、市、区县，点开详情是真实照片，不再出现生成图
- 关于「摄影大师比赛作品 / 百度 / B 站图片」：这些素材有明确版权，不能直接抓取或冒充实拍；本次改用**你的原创照片 + Unsplash 授权图**，B 站只作为视频搜索入口。若你有授权作品，放进 `data/uploads/materials/` 即可接入

### 影像志
- 46 张本机风景照，瀑布流展示
- 按城市 / 季节筛选，筛选条件写进网址
- 灯箱查看大图，带拍摄时间、坐标、尺寸、来源文件名，可上一张 / 下一张
- 只在本地读取文件并压缩，不上传云端

### 诗文
- 29 张实拍作品每一张都配了一句诗文：诗、词、赋、文，均取古典公版，注明作者与篇名
- 作品卡片显示半句，详情页展开完整题记与出处
- 上传作品时可以自己题一句；不填则按季节自动配一句
- 示例：`停车坐爱枫林晚，霜叶红于二月花。——杜牧《山行》`

### 地理 · 3D 地球
- **可转、可缩放**：鼠标拖拽旋转，滚轮缩放；手机双指缩放。原生 WebGL 球体，不依赖 three.js
- **更清晰的贴图**：优先加载 NASA Blue Marble 4096 贴图，4 秒未完成自动降级到 2048；最近可推到 1.48 倍半径，便于看省界附近的地貌
- **指哪点哪**：点击地球任意位置，解析经纬度，给出最近的机位、影像与地貌档案
- **寻找足迹 / 他人的照片**：
  - 「我的影像 42」：只显示带 GPS 的本机风景照
  - 「机位 8」：只显示实拍机位
  - 「地貌 11」：丹霞、喀斯特、雪山、沙漠、水乡、森林、海岸、草原、云海、雾凇、极光
- **世界地理 9 处**：撒哈拉、亚马孙、冰岛、阿尔卑斯、大堡礁、贝加尔湖、乌卢鲁、京都、荷兰圩田；覆盖自然地理与人文地理，点击会转动地球、切换背景并打开档案
- **按位置换背景**：允许定位后，按最近地貌切换背景，并按直线距离列出最近机位
- **地貌档案**：每张背景配地理说明、地理注脚与「看视频」（B 站搜索）
- 地球贴图：NASA Blue Marble（three.js 示例资源，支持 CORS）；失败时退化为线框地球

### 动态背景与图标
- 背景不只是静态图：水乡/云海有**飘动的雾**，喀斯特有**雨丝**，雪山/雾凇有**落雪**，丹霞/沙漠有**浮尘**，森林有**落叶**，海岸有**流动的浪线**，极光有**缓慢摆动的光幕**
- 11 种地貌都配了手绘线条图标（山、水、沙丘、树林、云、雪、极光），不是敷衍的圆点
- 页面切换使用 View Transitions + 卡片/图片分层入场；`prefers-reduced-motion` 下自动关闭

### 背景与影像来源
- 背景图优先使用**你桌面「素材」里的真实照片**（水乡、丹霞、喀斯特、森林、云海、雾凇），其余地貌优先使用 **Unsplash 在线大图**，加载失败时自动回落到本机照片
- 页面底部标明「Unsplash / 本机素材」，不使用 AI 生成图，也不使用程序绘制的风景
- 关于抖音：桌面版抖音的缓存是加密的、且内容版权归原作者，无法直接抓取；本次改用可商用的 Unsplash 与你的原创照片。若你有明确授权的素材，可以把文件放进 `data/uploads/materials/`，或在 `import_materials.py` 里追加清单

### 机位与作品
- 机位：封面、介绍、抵达经验、门票、人流、坐标、光线日历、镜头朝向分布
- 作品：大图、故事、拍摄提示、时间 / 季节 / 时段 / 朝向 / 站位 / 镜头
- 点赞、评论、同机位其他作品

### 上传
- 选择已有 8 个实拍机位，或新建机位
- 照片压缩到长边 1600px 后保存，自动生成缩略图
- 拍摄时间可手填；选图时读取文件时间推断季节与时段
- 罗盘拖动 / 滑块设置镜头朝向
- 首次发布、点赞、评论时设置本机昵称

### 我的
- 我的作品、我喜欢的、发布 / 获赞 / 评论统计、改昵称

## 快速开始

```powershell
cd shiguang-jiwei
python server.py --port 5187
```

打开 <http://127.0.0.1:5187>。也可以双击 `run.cmd`（会依次尝试 `python`、`py`、DSH 自带运行时）。

| 参数 | 说明 |
| --- | --- |
| `--port 5187` | 监听端口 |
| `--host 0.0.0.0` | 局域网访问，手机与电脑同一 Wi-Fi 时可打开 |
| `--reset` | 删除数据库与根目录示例图后重建；`data/uploads/materials/` 会保留并重新入库 |

### 重新导入桌面素材

当前导入是「人工策展 + 自动读取 EXIF」：`import_materials.py` 里维护了选中清单、标题、地点、机位映射与需要裁水印的编号。

```powershell
python import_materials.py
Remove-Item data\jiwei.db
python server.py --port 5187
```

脚本会重新读取 `C:\Users\1\Desktop\素材`，压缩输出到 `data/uploads/materials/`，并生成 `materials.json`；删除数据库后启动时自动重建全部机位与作品。要换素材目录，改脚本顶部的 `SOURCE`。

## 新增 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/materials` | 本机影像（`featured / city / province / season / spot / limit`） |
| GET | `/api/materials/{id}` | 单张影像 + 所在机位 |
| GET | `/api/atlas` | 所有带坐标的影像与机位、城市索引、范围 |

原有 `/api/spots`、`/api/works`、`/api/me`、点赞与评论接口不变。

## 数据模型（新增）

- `materials(id, idx, source, title, caption, place, province, city, lat, lng, taken_at, season, time_slot, image, thumb, width, height, spot_id, featured, created_at)`

8 个真实机位的作品同样写入 `works`，作者为「本机影像」，因此能直接复用点赞、评论、封面、光线日历等全部既有能力。

## 设计说明

- **为什么只留 8 个机位**：没有经过授权的「大师比赛作品」不能直接拿来当实拍。与其用生成图撑数量，不如只保留有真实照片来源的机位，并在卡片上把省、市、区县写清楚。16 个示例机位仍在数据库里作为资料，但公开接口不返回。
- **为什么是 3D 地球**：照片不是表格里的坐标，而是球面上的一群光点。转动地球找地方，比看列表更接近「想去哪里」的直觉；点选任意经纬度，又能把「未知的地方」变成可读的档案。
- **为什么背景用真实照片**：背景承担情绪，不承担信息。用真实风景（你的照片或 Unsplash）而不是生成图，才不会把「地理」做成一张壁纸。
- **人文气息**：宋体标题、卷首引文、编号与图注、胶片叠放、暖纸色与颗粒感；地理页采用暗场 + 玻璃面板，把视觉中心让给地球与照片。

## 已验证

- 数据：公开接口只返回 8 个实拍机位、29 张作品；16 个示例机位已隐藏
- 3D 地球：61 个光点渲染、贴图加载（4096/2048 回退）、拖拽旋转、点选经纬度返回最近机位
- 交互：筛选「我的影像」（机位光点隐藏）、切换丹霞/雪山/云海背景、点击城市旋转地球并切换背景、世界地理卡片打开档案
- 诗文：29 张作品全部有诗句与出处；上传可自定义，留空自动配
- 页面：桌面首页 / 机位库 / 影像志 / 3D 地球 / 作品详情 / 发布页，窄屏首页与影像志
- 影像灯箱：实际点击验证可打开、显示图片与元数据
- 早前的端到端流程（设置昵称 → 上传 → 点赞 → 评论）在无头浏览器中跑通

## 已知限制

- 公开机位只有 8 个（江苏 7、甘肃 1）；16 个示例机位因没有真实照片来源而不公开展示
- 「每个国家」目前是 **9 个世界地理档案**（自然/人文各选几处），不是完整世界图鉴；数据结构可继续扩充
- 摄影大师比赛作品、百度图片、B 站视频截图均有版权，未抓取；B 站仅作为视频搜索外链
- 3D 地球是自绘地理示意：没有国界、路网与地名搜索；点击只返回经纬度与最近档案
- 在线背景来自 Unsplash，需要联网；离线时自动回落到本机照片
- 定位功能需要浏览器允许位置，且只在 `localhost` 或 HTTPS 下可用
- 个别照片仍有相机水印（例如第 27 张）；如果介意可以把它从 `import_materials.py` 的清单里去掉
- 昵称是设备级身份，不是账号体系；图片存本机，正式上线需要对象存储、审核与隐私政策
- 本机照片涉及个人行踪，公开部署前必须获得照片中人物与拍摄者的授权
